# Ambient Sounds Setup

## Download Links (Royalty-Free)

The following sounds are **royalty-free** and can be used without attribution:

### 1. Rain Sound (ambient_rain.mp3)
**Source:** Mixkit - "Light rain loop" or "Forest rain loop"
- https://mixkit.co/free-sound-effects/rain/
- Download: "Light rain loop" or "Forest rain loop"
- Rename to: `ambient_rain.mp3`

### 2. Forest/Nature Sound (ambient_forest.mp3)
**Source:** Mixkit - "Birds in the jungle" or "Rain in the jungle and birds"
- https://mixkit.co/free-sound-effects/nature/
- Download: "Birds in the jungle" or "Morning birds"
- Rename to: `ambient_forest.mp3`

### 3. Ocean Waves Sound (ambient_waves.mp3)
**Source:** Mixkit - "Sea waves loop" or "Sea waves with birds loop"
- https://mixkit.co/free-sound-effects/ocean/
- Download: "Sea waves loop"
- Rename to: `ambient_waves.mp3`

### 4. Cafe Ambiance Sound (ambient_cafe.mp3)
**Source:** Free Sounds Library - "Cafe Ambience Sound" (CC BY 4.0)
- https://www.freesoundslibrary.com/cafe-ambience-sound/
- Download the MP3
- Rename to: `ambient_cafe.mp3`

## File Specifications

| File | Duration | Format | Size Target |
|------|----------|--------|-------------|
| ambient_rain.mp3 | 1-3 min loop | MP3 128kbps | ~1-2 MB |
| ambient_forest.mp3 | 1-3 min loop | MP3 128kbps | ~1-2 MB |
| ambient_waves.mp3 | 1-3 min loop | MP3 128kbps | ~1-2 MB |
| ambient_cafe.mp3 | 1-3 min loop | MP3 128kbps | ~1-2 MB |

## After Download

Place all 4 files in: `assets/sounds/`

```
justdoit/
├── assets/
│   └── sounds/
│       ├── ambient_rain.mp3
│       ├── ambient_forest.mp3
│       ├── ambient_waves.mp3
│       └── ambient_cafe.mp3
```
